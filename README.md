# Кофейня 12 — v3

Мобильная версия: главная занимает всю доступную высоту окна (100dvh), без имитации часов телефона и без рамки. Нижняя навигация находится в потоке, остальные разделы прокручиваются отдельно.

## GitHub Pages
Распакуйте архив в корень репозитория. В Settings → Pages выберите Deploy from a branch → main → /(root). Все пути относительные.

## Демо
Часы открывают профиль. Тестовые посещения сохраняются локально. Кнопка заказа открывает меню; онлайн-заказы, настоящая программа лояльности и авторизация не подключены. Изображения города — иллюстрации из концепта.

Файлы: index.html, style.css, app.js, assets/.
