# Кофейня 12

Статический мобильный сайт по предоставленному дизайн-референсу. HTML, CSS, JavaScript и локальные изображения. Без зависимостей, сборки, сторонних шрифтов или API. Изображения декора и городской архитектуры выделены из предоставленного макета, не являются подтверждёнными фотографиями Барнаула.

## Запуск
Откройте `index.html` в браузере. Или запустите из этой папки `python -m http.server 8000` и откройте `http://localhost:8000`.

## Публикация в GitHub Pages
1. Создайте публичный репозиторий на GitHub, например `coffee12`.
2. Загрузите **содержимое** архива в корень репозитория (index.html, style.css, app.js, assets/, .nojekyll, README.md). Сохраните структуру папок.
3. Откройте Settings → Pages → Build and deployment → Source: Deploy from a branch.
4. Выберите main и / (root), нажмите Save.
5. После успешной публикации сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/coffee12/`. Фактическая ссылка отображается в Settings → Pages.

## Что работает
- Главная, меню, события, профиль, меню-гамбургер и диалог адреса.
- Интерактивный SVG-циферблат: при тестовом посещении рука поворачивается на 30°, синий сегмент увеличивается. Счётчик сохраняется локально в браузере. Начальное состояние — 1 из 12, как в референсе.
- Кнопка заказа открывает демонстрационное меню, а не отправляет заказ. Реальный ассортимент, цены, режим работы и точный вход не предоставлены.
- Программа лояльности является демонстрацией, без авторизации, сервера, базы данных или подтверждения посещений бариста. Для настоящих бонусов потребуется серверная проверка и отдельный интерфейс сотрудника.
- Упоминаний коворкинга нет.

## Настройка
- `index.html`: тексты, разделы, адрес.
- `style.css`: оформление, размеры, цвет `--blue`.
- `app.js`: демонстрационное меню, логика циферблата, навигация.
- `assets/`: декоративные изображения из исходного референса. При запуске можно заменить иллюстрации на реальные фотографии с правами на публикацию.

Системная строка телефона и корпус устройства не имитируются; «12:00» вверху — часть фирменной идеи.
